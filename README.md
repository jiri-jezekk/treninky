# treninky

Aplikace pro **docházku na tréninky**, platby (QR ve formátu SPAYD) a skupinové výdaje.

Postaveno na [Next.js](https://nextjs.org).

## Lokální spuštění

1. Zkopíruj `.env.example` na `.env` a nastav `AUTH_SECRET` (dlouhý náhodný řetězec).
2. `npm install`
3. `npx prisma db push`
4. `npm run dev`

Aplikace běží na [http://localhost:3000](http://localhost:3000).
